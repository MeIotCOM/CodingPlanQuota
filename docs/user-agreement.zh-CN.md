1.1 本应用是第三方移动端工具，用于查询您已订阅的 AI 编程套餐（Coding Plan / Agent Plan 等，以下称「套餐」）的额度使用情况（如 5 小时窗口、周、月额度及重置时间）。

1.3 本应用不提供 AI 内容生成服务，仅对套餐额度信息进行只读查询与展示。

## 2. 账户与凭据

2.1 本应用不提供账号系统。使用时需您自行录入供应商签发的 API Key（部分供应商还要求组织 ID、项目 ID 等凭据）。
